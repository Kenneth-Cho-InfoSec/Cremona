Install Cremona

Native binaries. No Cremona runtime. No garbage collector.

Your first Cremona program

Build the compiler, run a script, then follow the same path into data work. This guide targets Cremona 0.5.0.

About 10 minutesStable Rust + a C compilerVersion 0.5.0

Before you start

Install stable Rust and a C compiler. Cremona uses Rust to build its compiler and a system C compiler to turn generated C11 into a native executable. Set CREMONA_CC if the C compiler is not discoverable as cc or gcc.

In a terminal, confirm that cargo --version and cc --version work.

1. Get the source and build

Clone the project, move into its directory, and build the workspace:

git clone https://github.com/Kenneth-Cho-InfoSec/Cremona.git
cd Cremona
cargo build --workspace

The compiler is created at target/debug/cremona. The first Rust build may take a few minutes.

2. Run the included program

The repository includes a hello-world example. Run it through Cremona:

./target/debug/cremona run examples/hello.cremona

Expected output:

hello, cremona

run compiles the source through C11, executes the resulting native program, and returns its exit status.

3. Write a small analysis

Save this as mean.cremona in the repository root. It uses a vector, a loop, and a function; the cast makes the division explicit.

fun mean(values: Vec<Float64>): Float64 {
    var total = 0.0
    for (value in values) {
        total += value
    }
    total / (values.len() as Float64)
}

println(mean(vec![2.0, 4.0, 6.0, 8.0]))

Run it with ./target/debug/cremona run mean.cremona. It prints 5. Check without linking by using ./target/debug/cremona check mean.cremona.
